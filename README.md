# dynamicCOLOURS
A simple but effective way to easily generate website colour palettes using only a base colour with CSS alone.

In both files, you will see that they are adapted to suit light and dark themes respectively. There is no reliable way in plain CSS to just reverse directions, so they will remain as-is until then.
You can simply swap between the two and create colour palettes for websites, with even the extreme cases of chroma-less black (`#000000`) and white (`#ffffff`) (They will produce pink accents).
